# Proyecto 7 - Cuadro de mandos de vehículos

# Análisis del Mercado de Vehículos Usados
Proyecto de análisis exploratorio de datos enfocado en identificar los factores que influyen en el precio de vehículos usados utilizando datos reales de anuncios de venta.
Este proyecto aplica técnicas de limpieza de datos, transformación, análisis exploratorio y visualización para descubrir patrones dentro del mercado de autos usados.

# Objetivo del proyecto
El objetivo principal de este análisis es comprender cómo diferentes características de los vehículos afectan su precio en el mercado de segunda mano.
Se analizaron variables como:
- kilometraje
- antigüedad del vehículo
- condición
- tipo de combustible
- tipo de vehículo
- tiempo que el vehículo permanece listado

El análisis permite identificar tendencias que pueden ayudar a entender el comportamiento del mercado de autos usados.

# Tecnologías utilizadas
Este proyecto fue desarrollado utilizando:
- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Plotly**
- **Streamlit**

Esta aplicación web (Streamlit) muestra un análisis exploratorio básico del conjunto de datos `vehicles_us.csv` (anuncios de venta de coches).
Permite generar visualizaciones interactivas con Plotly:
- Histograma del odómetro (odometer)
- Gráfico de dispersión entre odometer y price

**App en vivo:** https://proyecto7-10li.onrender.com

# Principales hallazgos

Algunos insights obtenidos durante el análisis incluyen:
- Los vehículos con menor kilometraje tienden a tener precios más altos.
- Los vehículos más nuevos presentan un valor significativamente mayor.
- El tipo de vehículo influye en la distribución de precios.
- Algunos anuncios permanecen más tiempo en el mercado dependiendo de sus características.
